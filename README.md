#  The Confidently Incorrect AI

##  The Original Idea

The idea behind this project came from a problem I often faced while using Discord.

I had joined several Discord communities where people sent hundreds of messages every day. Whenever I wanted to join a conversation or simply understand what everyone was discussing, I had to scroll through the chat, read message after message, and figure out the context myself.

It was time-consuming.

So, I decided to build a local AI assistant that could:

- Read messages sent by members of a Discord group.
- Generate a simple overview of the conversation.
- Explain what people were discussing in easy-to-understand language.
- Help me understand the context without reading hundreds of individual messages.
- Suggest possible replies based on the conversation.

The goal was simple: **Let AI catch me up on conversations so I wouldn't have to scroll endlessly.**

##  What It Eventually Became

Well, things didn't go exactly as planned.

During testing, I discovered that my AI had some rather unusual interpretations of reality.

For example:

| Question | AI's Answer |
|---|---|
| Who is Rahul Gandhi? | Vice President of India |
| Who is Narendra Modi? | Former PM |

Apparently, this AI isn't living in the present. It's operating on its own timeline.

And that's how an attempt to build a useful Discord assistant turned into a confidently incorrect AI from the future.

## Tech Stack

- JavaScript
- HTML & CSS
- Chrome Extension Manifest V3
- Ollama
- DeepSeek-R1 1.5B

## What I Learned

- Building Chrome extensions
- Connecting JavaScript to a local LLM
- Working with Ollama's API
- Debugging CORS errors
- Understanding the limitations of small language models

## Known Limitations

- Sometimes generates factually incorrect answers.
- Struggles with anime references and internet slang.
- Does not have built-in live web search.
- Can confidently produce incorrect information.

##  Project Status

Experimental prototype. Development currently paused.

## Disclaimer

This project is for educational and experimental purposes.
AI-generated answers should not be treated as factual information.
